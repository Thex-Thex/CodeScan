# CodeScan
A versatile, open-source tool for scanning, managing, and generating both barcodes and QR codes. Designed for fun, but also might be used inventory management. 

## description

- This project provides barcode and QR code scanning using a USB 1D/2D scanner.
- tools to generate barcodes
- tools to generate QR codes containing data that can be easily read by smartphones.
